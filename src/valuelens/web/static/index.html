SEC EDGAR IDENTITY

What it is. The SEC's free database of company filings: 10+ years of income statements, balance sheets and cash flows for every US-listed company.

How to get it. Nothing to sign up for. The SEC asks every automated tool to say who is behind it, so type your own name and an e-mail address you read.

How it is checked. We confirm the e-mail's domain receives mail and that the SEC accepts the identity. Nothing is stored: it lives in this tab only and is sent to sec.gov with each request. SEC access rules

 required
FRED API KEY

What it is. The St. Louis Fed's economic database. ValueLens reads two rates from it: the AAA corporate bond yield (Graham's formula) and the 10-year Treasury yield (the discount rate).

How to get it. Free: create an account at fredaccount.stlouisfed.org, open API Keys, request a key and paste the 32-character code here.

Limit. 120 requests per minute per key; one analysis uses 2, and rates are cached for a day. Without a key the same rates come from FRED's public download.

 optional

    We cannot read your inbox: the e-mail check confirms the domain accepts mail and that the SEC accepts the identity, not that the mailbox is yours. Use your own.
